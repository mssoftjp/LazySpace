# LazySpace

いつものMacのまま、ウインドウを自動で並べるアプリです。

LazySpaceを起動したら、あとは普段どおりに作業するだけです。操作スペースごとにウインドウがひとりでに整い、操作スペースもMission Controlもフルスクリーンも、今までと何も変わりません。覚えることも、設定することもありません。ウインドウを並べる手間はLazySpaceが引き受けます。

[English](README.md) · [使い方](docs/guide.ja.md) · [Releases](https://github.com/mssoftjp/LazySpace/releases)

## LazySpaceを作った背景

きっかけはAeroSpaceでした。ウインドウが自動で並ぶ快適さは一度味わうと手放せなくなるもので、AeroSpaceはそれをとてもうまく実現しています。ただ、そのぶん求められるものもあります。独自のワークスペースを理解し、ショートカットを覚え、その流儀に慣れるまでには少し時間がかかるかもしれません。

LazySpaceは、良いところだけを残して敷居を下げました。macOSにもともとある操作スペースの上で動くので、Mission ControlもフルスクリーンもSplit Viewも、今までどおりに使えます。ウインドウは勝手に並びますし、マウスだけで一日過ごしても困りません。ショートカットは、使いたくなったときに使えば十分です。

## インストール

```bash
brew install --cask mssoftjp/tap/lazyspace
```

または、[Releases](https://github.com/mssoftjp/LazySpace/releases)からDMGをダウンロードし、LazySpace.appを「アプリケーション」フォルダへ入れます。

1. LazySpaceを開きます。メニューバーにアイコンが出ます。
2. macOSが許可を求めてきたら、システム設定 › プライバシーとセキュリティ › 「デバイスの制御とデータへのアクセス」でLazySpaceをオンにします（macOS 26までは「アクセシビリティ」）。
3. これだけです。さっきの作業に戻ってください。

macOS 14以降とApple Siliconが必要です。自分でビルドしたい場合は[ソースからビルドする](docs/guide.ja.md#ソースからビルドする)を見てください。

## 作業中に起きること

**ウインドウはひとりでに並びます。** 操作スペースで普段どおりに作業していると、そこにあるウインドウが作業領域を分け合うように並びます。新しく開いたウインドウは、使っていたウインドウの隣に入ります。ウインドウを閉じれば、残りのウインドウが空いた場所を埋めます。

**レイアウトは操作スペースごとです。** 並べてほしくない操作スペースでは、メニューの「この操作スペースを自動整列」をオフにします。並べてほしくないアプリは、設定 › アプリに登録します。

**ディスプレイが複数あっても迷いません。** メニューにはディスプレイごとに操作スペースが並び、別のディスプレイのデスクトップへもメニューからウインドウを送れます。

## しないこと

- 独自のワークスペースを作りません。ウインドウを画面の外に隠しません。
- Macが操作スペースを切り替える仕組みを変えません。切り替えには、macOSのショートカット「デスクトップNへ切り替え」、移動先にすでにあるウインドウやアプリ、Mission Controlのショートカット「左の操作スペースに移動」「右の操作スペースに移動」を使います。これらの設定は読むだけで、書き換えません。
- ウインドウのタイトルを保存しません。入力した内容も記録しません。
- 設定の「一般」でオンにしない限り、通知を送りません。
- ネットワークにつなぐのは、GitHubへのアップデート確認（1日1回の自動確認はオフにできます。自分で確認することもできます）と、自分で選んだアップデートのダウンロードだけです。

## マウスでも、キーボードでも、コマンドでも

日々の操作はマウスだけで足ります。ウインドウの境目をドラッグすれば大きさが変わり、別のウインドウの上に落とせば位置が入れ替わります。

もっと速く操作したくなったら、ショートカットがあります。既定の配置の多くはAeroSpaceに近いようにしています。修飾キーを1秒ほど押したままにすると一覧が出ます。変えたいときは設定 › ショートカットで変えられます。

| キー | 操作 |
|---|---|
| `⌥H` `⌥J` `⌥K` `⌥L` | 左・下・上・右のウインドウへフォーカス |
| `⌥⇧H` `⌥⇧J` `⌥⇧K` `⌥⇧L` | ウインドウをその方向へ移動 |
| `⌥Z` | ウインドウを作業領域いっぱいに広げる / 戻す |
| `⌥F` | ウインドウをタイルから外す / 戻す |
| `⌥1` … `⌥9` | デスクトップ1〜9へ切り替え |
| `⌥⇧1` … `⌥⇧9` | ウインドウをデスクトップ1〜9へ送る。自分はその場に残る（macOS 27が必要） |
| `⌥⇥` | 直前の操作スペースに戻る |

ショートカットでできることは、すべてコマンドでもできます。

```bash
lazyspace focus left
lazyspace space 2
lazyspace move-to-space 3 --follow
lazyspace list-windows      # which windows are tiled here, and why not
lazyspace status            # what LazySpace is doing, and the latest result
```

`--json`を付けると、スクリプトやAIエージェントが読める形で結果が返ります。操作が完了したのか、途中で止まったのか、止まったならなぜかも結果に入っています。詳しくは[Scripting and agents](docs/scripting.md)（英語）を見てください。
