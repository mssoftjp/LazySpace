# LazySpaceの使い方

インストールから設定ファイルまで、LazySpaceの使い方を説明します。概要は[README](../README.ja.md)にあります。

## インストール

macOS 14以降とApple Siliconが必要です。Homebrewでインストールします。

```bash
brew install --cask mssoftjp/tap/lazyspace
```

LazySpace.appと`lazyspace`コマンドが入ります。[GitHub Releases](https://github.com/mssoftjp/LazySpace/releases)からDMGをダウンロードし、LazySpace.appを「アプリケーション」フォルダへドラッグしてもかまいません。

### ソースからビルドする

ビルドにはXcode 27が必要です。

```bash
git clone https://github.com/mssoftjp/LazySpace.git
cd LazySpace
script/build.sh
```

テストを実行したうえで`dist/dev/LazySpace.app`を作ります。「アプリケーション」フォルダへ移して開いてください。キーチェーンにApple Developmentの証明書が1つだけあればそれで署名します（`DEVELOPMENT_SIGNING_IDENTITY`で指定もできます）。それ以外はアドホック署名になり、ビルドのたびに許可をやり直す必要があります。

### Homebrewを使わない場合の`lazyspace`コマンド

DMGやソースからインストールしたときは、`PATH`の通った場所にリンクを作ります。

```bash
sudo mkdir -p /usr/local/bin
sudo ln -s /Applications/LazySpace.app/Contents/Resources/bin/lazyspace /usr/local/bin/lazyspace
```

## はじめかた

1. LazySpaceを開きます。メニューバーにアイコンが出ます。
2. 初回はmacOSが許可を求め、設定の「一般」が開きます。「システム設定を開く…」を押し、「プライバシーとセキュリティ」の「デバイスの制御とデータへのアクセス」（macOS 26までは「アクセシビリティ」）でLazySpaceをオンにします。あとからでも、「ウインドウを確認…」の「対処を確認…」から同じ画面へ進めます。
3. 操作スペースでそのまま作業します。その操作スペースに1秒ほどとどまり、入力がなければ、LazySpaceがウインドウを整列します。ウインドウが1つなら、作業領域（画面からメニューバーとDockを除いた範囲）いっぱいに広がります。
4. ウインドウを増やします。新しいウインドウは、使っていたウインドウの隣に入ります。

そのままにしておきたい操作スペースでは、その操作スペースにいる間にメニューバーの「この操作スペースを自動整列」をオフにします。整列させたくないアプリは、設定の「アプリ」に追加します。

## 日々の使い方

### メニューバー

| 項目 | 内容 |
|---|---|
| **ウインドウを別の操作スペースへ** | フォーカス中のウインドウを、このディスプレイか別のディスプレイのデスクトップへ送ります。設定 › ショートカットの「ウインドウを別の操作スペースに移動するときに、その操作スペースに切り替える」がオフなら、表示中の操作スペースは変わりません（別のディスプレイへ送るときは下の説明を参照）。デスクトップが2つ以上あり、フルスクリーンの操作スペースにいないときだけ出ます |
| **レイアウトを編集** | フォーカス中のウインドウに対するレイアウトの操作です |
| **この操作スペースを自動整列** | 今の操作スペースの自動整列をオン・オフします |
| **今すぐ整列** | 今の操作スペースを整列し、整列を始めます（`⌥⇧A`）。上の自動整列の設定は変えません |
| **待機中のウインドウを1つ追加** | 自動で加われなかったウインドウを追加します。待機中のウインドウがあるときだけ出ます |
| **LazySpaceを一時停止** | 再開するまで、すべての整列を止めます。再開しただけではウインドウは動きません |
| **ウインドウを確認…** | この操作スペースのウインドウが整列対象かどうかと、対象でない理由を表示します |
| **設定…** | 設定を開きます（`⌘,`） |

アイコンの横の数字は、今いるデスクトップの番号です。複数のディスプレイをつないでいるときは、各ディスプレイが表示しているデスクトップの番号を、下の一覧と同じ順に`4|1`のように並べます。このとき番号のない操作スペース（フルスクリーンの操作スペースや、一瞬読み取れないとき）は`–`になります。今いるのはフォーカス中のウインドウがあるディスプレイで、数字には印を付けません。

メニューの上部には、操作スペースの一覧と、それぞれにあるアプリが表示されます。複数のディスプレイをつないでいるときは、どちらの一覧も、macOSが表示するディスプレイの名前（システム設定 › ディスプレイの名前）ごとに分かれ、各ディスプレイが表示している操作スペースにチェックマークが付きます。同じ名前のディスプレイが2台あるときは、「LG HDR 4K (1)」のようにディスプレイの順の番号を付けます。上部の一覧で別のディスプレイの操作スペースを選ぶと、そこへ切り替えます。上部の一覧で操作スペースを右クリックすると、「ウインドウを別の操作スペースへ」でそれを選んだときと同じように、フォーカス中のウインドウをそこへ送ります。

### キーボードショートカット

修飾キーを1秒ほど押したままにすると、ショートカットの一覧が出ます（設定の「ショートカット」でオフにできます）。ショートカットもそこで変えられます。

| キー | 操作 | 設定とメニューでの名前 |
|---|---|---|
| `⌥H` `⌥J` `⌥K` `⌥L` | 左・下・上・右のウインドウへフォーカス | 「左のウインドウに切り替え」「下のウインドウに切り替え」「上のウインドウに切り替え」「右のウインドウに切り替え」 |
| `⌥⇧H` `⌥⇧J` `⌥⇧K` `⌥⇧L` | ウインドウをその方向へ移動 | 「左へ並べ替える」「下へ並べ替える」「上へ並べ替える」「右へ並べ替える」 |
| `⌥⌃H` `⌥⌃J` `⌥⌃K` `⌥⌃L` | その方向のウインドウと交換 | 「左のウインドウと交換」「下のウインドウと交換」「上のウインドウと交換」「右のウインドウと交換」 |
| `⌥⌘H` / `⌥⌘L` | 幅を狭く / 広く | 「幅を狭める」 / 「幅を広げる」 |
| `⌥⌘K` / `⌥⌘J` | 高さを低く / 高く | 「高さを減らす」 / 「高さを増やす」 |
| `⌥-` / `⌥=` | 分割の中での割合を小さく / 大きく | 「並び方向に縮める」 / 「並び方向に広げる」 |
| `⌥⇧B` | レイアウトの割合をそろえる | 「分割の割合を均等にする」 |
| `⌥/` | 横並びと縦積みを切り替え | 「縦並び／横並びを切り替え」 |
| `⌥,` | タイルとアコーディオンを切り替え | 「重ねて表示／並べて表示」 |
| `⌥F` | ウインドウを整列対象から外す / 戻す | 「整列対象から外す／戻す」（メニューでは「整列対象から外す」または「整列対象に戻す」） |
| `⌥Z` | ウインドウを作業領域いっぱいに広げる / 戻す | 「作業領域いっぱいに表示／戻す」（メニューでは「作業領域いっぱいに広げる」または「整列した表示に戻す」） |
| `⌥B` | 直前のウインドウへフォーカス | 「直前のウインドウに戻る」 |
| `⌥⇧Z` | 直前のレイアウト変更を取り消す | 「レイアウト変更を取り消す」 |
| `⌥⇧A` | この操作スペースを今すぐ整列 | 「この操作スペースを整列」（メニューでは「今すぐ整列」） |
| `⌥⇧I` | 待機中のウインドウを1つ追加 | 「待機中のウインドウを1つ追加」 |
| `⌥1` … `⌥9` | デスクトップ1〜9へ切り替え | 「デスクトップ1へ切り替え」…「デスクトップ9へ切り替え」 |
| `⌥⇧1` … `⌥⇧9` | フォーカス中のウインドウをデスクトップ1〜9へ送る（操作スペースは切り替えない。設定で一緒に移るようにもできる。下の「操作スペース」を参照） | 「ウインドウをデスクトップ1へ送る」…「ウインドウをデスクトップ9へ送る」（一緒に移る設定では「ウインドウをデスクトップ1へ移動して切り替え」…） |
| `⌥⇥` | 直前の操作スペースへ戻る | 「直前の操作スペースへ移動」 |

`⌥`はOption、`⇧`はShift、`⌃`はControl、`⌘`はCommandです。キーボード配列によっては、Optionと英字の組み合わせで特殊文字が入力されます。その場合は設定画面が注意を出すので、別のキーを選んでください。

### マウス

自動整列がオンのとき、整列されたウインドウをマウスで編集できます。

- 2つのウインドウの境目をドラッグすると、大きさを変えられます。
- ウインドウを整列された別のウインドウの上に落とすと、入れ替わります。
- それ以外の場所に落とすと、元の位置に戻ります。

### 操作スペース

- `⌥1`〜`⌥9`（または`lazyspace space N`）で、番号のデスクトップへ切り替えます。番号はMission Controlの並び順で、フルスクリーンとSplit Viewの操作スペースには付きません。複数のディスプレイでは、番号はディスプレイごとに数え、これらのショートカットはフォーカス中のウインドウがあるディスプレイに使います。
- `⌥⇧1`〜`⌥⇧9`（または`lazyspace move-to-space N`）で、フォーカス中のウインドウを別のデスクトップへ送ります。表示中の操作スペースは変わりません。この操作にはmacOS 27が必要です。コマンドラインで`--follow`を付けると、ウインドウと一緒に移ります。別のディスプレイのデスクトップへは、メニューを使うか、コマンドラインで`--display N`（`lazyspace list-spaces`でのディスプレイの順番）を付けます。このときmacOSは送ったウインドウにフォーカスを移しますが、LazySpaceが直前のウインドウを前面に戻すので、このディスプレイに留まります。戻すウインドウがないとき、または戻せなかったときは、フォーカスは送ったウインドウとともに移ります。
- ショートカットとメニューでもウインドウと一緒に移るには、設定 › ショートカットの「ウインドウを別の操作スペースに移動するときに、その操作スペースに切り替える」をオンにします（ファイルでは`follow-moved-window`）。`⌥⇥`で元の操作スペースに戻れます。コマンドラインには影響しません。`lazyspace move-to-space N`は常にその場に残り、`--follow`は常にウインドウと一緒に移ります。macOS 27より前では、この設定がオンのときだけ、ショートカットとメニューでウインドウを移せます。このときLazySpaceはウインドウのタイトルバーをつかんだまま切り替えるので、ポインタが一瞬動きます。タイトルバーをドラッグできないウインドウは移せません。
- 切り替えには、Macにすでにあるものを使います。macOSのショートカット「デスクトップNへ切り替え」がオンならそれを使い、次に移動先のウインドウやアプリを使い、それもなければMission Controlのショートカット「左の操作スペースに移動」「右の操作スペースに移動」（初期設定でオン）を使います。LazySpaceはこれらのショートカットを変更しません。必要なショートカットがオフのときは、何も送りません。
- 番号を固定するには、システム設定 › デスクトップとDockの「最新の使用状況に基づいて操作スペースを自動的に並べ替える」をオフにしてください。
- 切り替えの途中でキーやマウスを操作すると、その操作は止まります。

## 設定

メニューバーの「設定…」から開きます。

- **一般**: アクセス権、「ログイン時に開く」、言語、通知。
- **整列**: 大きさが固定のウインドウを整列したウインドウと並べて表示するか、ウインドウの間隔、新しいウインドウの位置、フォーカス中のウインドウの枠線（任意）。
- **ショートカット**: mainモードのショートカット。ダブルクリックするかReturnを押すと変更できます。Deleteで割り当てを解除し、Option-Deleteでデフォルトに戻し、「デフォルトに戻す」で一覧全体を戻します。一覧の下には、隣の操作スペースへ切り替えられないときだけ警告が出て、何を直せばよいかを示します。一覧の上の「ウインドウを別の操作スペースに移動するときに、その操作スペースに切り替える」をオンにすると、操作スペースのショートカットとメニューでウインドウを移したときに、一緒に切り替わります。
- **アプリ**: 整列しない、またはフローティングにしておくアプリ。各行にはアプリ名とバンドル識別子が並びます。名前は起動中またはインストール済みのアプリから取るので、インストールされていないアプリと`com.microsoft.*`のような前方一致のルールでは空欄です。編集できるのは識別子です。
- **詳細**: 設定ファイル。
- **情報**: バージョン、GitHubのソースコードへのリンク、アップデート。

モードとその入口のショートカットは、設定ファイルでだけ編集します。

変更はその場で保存されます。言語は、選ばない限りmacOSに合わせます。

### 通知

LazySpaceは、オンにしない限り通知を送りません。設定の「一般」で「対処が必要なときに通知」をオンにすると、何かをしないとLazySpaceが整列を再開できないときに、macOSの通知で知らせます。アクセス権がオフになったとき、自動整列が止まったとき（ステージマネージャを使っているときなど）、設定ファイルの変更を適用できないときです。ほかのことでは通知しません。オンにすると、LazySpaceが通知を送ってよいかをmacOSが一度だけ確認します。表示のしかた（「一時的」か「持続的」か）は、システム設定 › 通知で選びます。音は鳴りません。通知をクリックすると、直すための画面が開きます。LazySpaceの起動時にすでに設定ファイルに誤りがある場合は、通知ではなく、メニューと設定に表示します。

## アップデート

LazySpaceは、1日に1回GitHubで新しいバージョンを確認します。新しいバージョンがあっても、画面には何も出ません。設定の「情報」に「アップデート…」ボタンが出て、メニューバーのメニューに「LazySpace 0.5.1にアップデート…」（新しいバージョンの番号）が加わります。どちらからでもアラートが開き、インストールするか、「あとで通知」にするか、そのバージョンをスキップするかを選べます。インストールするとLazySpaceが再起動し、新しいバージョンが開きます。自動でインストールされることはありません。「情報」の「アップデートを確認…」を押すとすぐに確認し、スキップしたバージョンも表示します。毎日の確認を止めるには、「情報」の「アップデートを自動的に確認」をオフにします。オフでも「アップデートを確認…」は使えます。

Homebrewでインストールした場合も、同じ方法でアップデートします。自分でビルドしたときと、ディスクイメージから直接開いたときは、アップデートを確認しません。

## 設定ファイル

設定は、設定画面からでも、ファイル`~/.config/lazyspace/config.toml`からでも変えられます。ファイルを書き換えると自動で読み込まれます。ファイルに誤りがあるときは読み込まず、それまでの設定を使い続けます。設定画面から保存してもファイルのコメントは残り、直前の内容は`config.toml.bak`に保存されます。新しく作られるファイルは、コメントも含めて英語です。別の場所を使うときは`LAZYSPACE_CONFIG`を指定します。

### よく使う設定

| 設定 | 既定値 | 意味 |
|---|---|---|
| `language` | `"system"` | `"system"`、`"en"`、`"de"`、`"es"`、`"fr"`、`"ja"`、`"ko"`、`"pt-BR"`、`"zh-Hans"`、`"zh-Hant"` |
| `gap` | `0` | ウインドウの間隔（0〜200ポイント。整数に丸めます）。`[gaps]`の`inner-horizontal`、`inner-vertical`、`outer-left`、`outer-top`、`outer-right`、`outer-bottom`で別々に指定できます（それぞれ0〜200） |
| `place-dialogs-beside` | `false` | 計算機や警告など大きさが固定のウインドウから別のウインドウへ移ると、そのウインドウを右端か下端の帯へ移し、整列したウインドウは残りに並べる |
| `follow-moved-window` | `false` | ショートカットかメニューでウインドウを別の操作スペースへ移したあと、その操作スペースにも切り替える。コマンドラインには影響しない |
| `new-window-placement` | `"beside-focused"` | 新しいウインドウの位置。`"end"`なら末尾に追加します |
| `focus-after-close` | `true` | フォーカス中のウインドウを閉じ、同じ操作スペースのどのウインドウにもフォーカスがないとき、近くのウインドウへフォーカスする |
| `accordion-padding` | `30` | アコーディオンでほかのウインドウを見せる帯の幅（0〜200ポイント。整数に丸めます） |
| `preferred-minimum` | `[400, 300]` | 行数と、高さの小さいウインドウの下の空きに新しいウインドウが入るかを決める目安の大きさ（それぞれ0〜100000ポイント）。最小サイズを強制するものではありません |
| `unknown-floor` | `[120, 120]` | アプリが最小サイズを返さないときに仮定する大きさ（それぞれ0〜100000ポイント） |
| `quiet-interval` | `0.6` | 操作スペースで自動整列を始める前と、マウスでドラッグしたあとに、入力が止まっている必要がある時間（秒、0.1〜10）。通常のウインドウの追加や削除では、この時間を待たないことがあります。マウスでの大きさの変更や入れ替えも、ウインドウが静止すればこの時間より前に反映されることがあります |
| `per-app-timeout` | `2.0` | アプリの応答を待つ時間（秒、0.2〜30） |
| `start-at-login` | 未設定 | ログイン時に開く。未設定ならmacOSのログイン項目をそのままにします |
| `show-shortcut-guide` | `true` | 修飾キーを1秒ほど押したままにすると、ショートカットの一覧を出す。オフでもショートカットは使えます |
| `[focus-border]` | オフ | `enabled`、`width`（1〜12ポイント）、`color`（`"#RRGGBB"`または`"#RRGGBBAA"`） |
| `[notifications]` | オフ | `needs-attention`：対処が必要なときにmacOSの通知で知らせる（上の「通知」を参照） |
| `[keys]` | 上のショートカット | キーボードショートカット。操作に`"none"`を指定すると割り当てを外します |

### 例

```toml
gap = 8

# Hooks for status bars. Top-level settings go before any [table].
# Commands run directly; use /bin/sh -c for shell features.
exec-on-space-change = ["/bin/sh", "-c", "sketchybar --trigger space_change"]
exec-on-mode-change  = ["/bin/sh", "-c", "sketchybar --trigger mode_change"]
exec-on-window-sent  = ["/bin/sh", "-c", "sketchybar --trigger window_sent"]

[[rule]]
app = "com.apple.calculator"   # bundle identifier; a trailing * matches a prefix
action = "float"               # keep it where it is; "ignore" leaves it out entirely

[[rule]]
app = "com.google.Chrome"
title = "Meet"                 # optional regular expression for the window title
action = "space"               # send new windows of this app to another Space
space = 3                      # desktop number
follow = false                 # true also switches to that Space

[keys]
zoom = "none"                  # remove a shortcut
space-1 = "f1"
```

`float`は位置をそのまま保ち、`ignore`は整列から完全に外します。`action = "space"`のルールは、そのアプリの新しいウインドウを別の操作スペースへ送ります。送るのは、LazySpaceの起動中に開いたウインドウだけです。

コマンドはシェルを通さずに直接実行します。パイプなどを使うときは`/bin/sh -c`を指定してください。フックには環境変数で情報を渡します。操作スペースの変化では`LAZYSPACE_SPACE_ID`と`LAZYSPACE_PREV_SPACE_ID`、モードの変化では`LAZYSPACE_MODE`、ルールでウインドウを送ったときは`LAZYSPACE_WINDOW_ID`、`LAZYSPACE_APP`、`LAZYSPACE_FROM_SPACE`、`LAZYSPACE_TO_SPACE`、`LAZYSPACE_FROM_DISPLAY`、`LAZYSPACE_TO_DISPLAY`、`LAZYSPACE_FROM_SPACE_ID`、`LAZYSPACE_TO_SPACE_ID`です。`LAZYSPACE_FROM_SPACE`と`LAZYSPACE_TO_SPACE`はそれぞれのディスプレイで数えたデスクトップの番号で、番号のない操作スペースでは空です。`LAZYSPACE_FROM_DISPLAY`と`LAZYSPACE_TO_DISPLAY`は`list-spaces`でのディスプレイの順番で、分からないときは空です。`_SPACE_ID`で終わる変数はmacOSの操作スペースのID、`LAZYSPACE_WINDOW_ID`はウインドウのIDです。ウインドウのタイトルは渡しません。`exec-on-window-sent`はルールでウインドウを送ったときだけ実行し、メニューやコマンドラインから送ったときは実行しません。

フックは、LazySpaceのアクセシビリティの許可ではなく、そのコマンド自身のmacOSの許可で動きます。ほとんどのコマンドは許可がなくても動きます。フックからウインドウを並べたいときは、`lazyspace`コマンドを使ってください。

### モード

モードは設定ファイルでだけ定義します。モードの中では、修飾キーなしのキーも使えます。

```toml
[keys]
mode-review = "alt-g"

[mode.review]
return-to-main = true          # go back to the main mode after one command
[mode.review.keys]
mode-main = "esc"
float = "f"
```

`main`以外のモードのときは、モード名がメニューバーに表示されます。

### `[keys]`で使う名前

操作: `focus-`、`swap-`、`move-`、`join-`に`left`、`down`、`up`、`right`を続けたもの、`focus-back`、`resize-width-grow`、`resize-width-shrink`、`resize-height-grow`、`resize-height-shrink`、`resize-smart-grow`、`resize-smart-shrink`、`balance`、`toggle-split`、`accordion`、`float`、`zoom`、`undo`、`close`、`fullscreen`、`minimize`、`space-1`〜`space-9`、`space-next`、`space-prev`、`space-back`、`move-to-space-1`〜`move-to-space-9`、`move-to-space-next`、`move-to-space-prev`、`move-to-space-follow-1`〜`move-to-space-follow-9`、`move-to-space-follow-next`、`move-to-space-follow-prev`、`arrange`、`integrate`、`pause-resume`、`reload`、`mode-main`、`mode-<名前>`。

キー: `a`〜`z`、`0`〜`9`、`f1`〜`f20`、`minus`、`equal`、`comma`、`period`、`slash`、`semicolon`、`quote`、`backslash`、`backtick`、`leftSquareBracket`、`rightSquareBracket`、`space`、`enter`、`tab`、`esc`、`backspace`、`forwardDelete`、`left`、`right`、`up`、`down`、`home`、`end`、`pageUp`、`pageDown`、`keypad0`〜`keypad9`、`keypadDecimal`、`keypadMultiply`、`keypadPlus`、`keypadClear`、`keypadDivide`、`keypadEnter`、`keypadMinus`、`keypadEquals`、`yen`、`underscore`、`eisu`、`kana`、`sectionSign`に、`alt`、`shift`、`ctrl`、`cmd`を組み合わせます（例: `alt-shift-h`）。名前は物理的なキーを指します。mainモードのショートカットには、ファンクションキーを除いて修飾キーが必要です。

## コマンドライン

```bash
lazyspace status           # what LazySpace is doing, and the latest result
lazyspace list-windows     # windows in this Space, and why any are not tiled
lazyspace arrange
lazyspace focus left
lazyspace space 2
lazyspace move-to-space 3 --follow
```

すべてのコマンドは`lazyspace help`で確認できます。アプリとやり取りするコマンドは、`--json`を付けると機械で読める形式で出力します（`help`と`version`はテキストだけです）。メッセージは表示言語に従うので、スクリプトでは構造化された項目を読んでください。終了コードは、`0`が完了、`1`が拒否・一部完了・中断、`2`がアプリと通信できなかったときです。スクリプトやAIエージェントから使う場合は、[Scripting and agents](scripting.md)（英語）を参照してください。

## AeroSpaceから移る場合

既定のショートカットは、同じ操作があるものはAeroSpaceに合わせています。違いは次のとおりです。

- **移動**（`⌥⇧`と方向）は、その方向の分割で隣り合うウインドウと位置を入れ替え、それぞれ分割の中の割合を保ちます（AeroSpaceと同じです）。それ以外では隣のウインドウの横に入れ直すので、大きさが変わります。上下に移動すると、2つのウインドウは列の高さを分け合う状態に戻ります。**交換**（`⌥⌃`と方向）は、2つのウインドウのレイアウト上の位置を入れ替えます。
- **`⌥-` / `⌥=`** は、分割の中での割合を5%ずつ変えます。決まったポイント数ではありません。
- **`⌥1`〜`⌥9`** は、Mission Controlの並び順で既存のデスクトップを選びます。ないデスクトップは作りません。
- serviceモードは組み込まれていません。使う場合は設定ファイルで定義します。グループ化（join）には既定のショートカットがありません。

## 困ったとき

- **ウインドウが整列されない。** 「ウインドウを確認…」を選ぶか、`lazyspace list-windows`を実行すると理由が分かります。大きさが固定のウインドウ、フルスクリーンのウインドウ、アプリのルールなどです。
- **ショートカットを押しても何も起きない。** `lazyspace status`の「直近の通知」を見てください。ショートカットが拒否されても、LazySpaceは画面にメッセージを出しません。
- **自動整列が使えない。** 「ウインドウを確認…」に「対処を確認…」が出て、変える設定を案内します。止まったときに知りたい場合は、設定の「一般」で通知をオンにしてください。
- **`⌥1`〜`⌥9`で違うデスクトップへ行く。** 「最新の使用状況に基づいて操作スペースを自動的に並べ替える」をオフにしてください。
- **隣の操作スペースへ切り替えられない。** 設定の「ショートカット」を確認してください。問題があれば、直し方とともに警告が出ます。macOSが応答していないと出たときは、Macからログアウトしてログインし直してください。
- **ショートカットで文字が入力される。** 設定の「ショートカット」で別のキーを選んでください。

## プライバシー

LazySpaceは、ウインドウを読み取って並べるためにアクセシビリティを使います。ウインドウのタイトルはルールとの照合にだけ使い、保存しません。入力は回数だけを数え、入力した文字は記録しません。操作の履歴も残しません。直前の操作の結果は`lazyspace status`のためにメモリにだけ持ち、保存するのは操作スペースごとの並べ方だけです。LazySpace自身がネットワークに接続するのは、1日に1回GitHubでアップデートを確認するとき（「情報」でオフにできます）と、選んだアップデートをダウンロードするときだけです。確認で送るのはアプリの名前とバージョンだけで、Macやウインドウの情報は送りません。通知には、何が止まったかと何をすればよいかだけを書き、ウインドウのタイトルや設定ファイルの中身は入れません。フックに設定したコマンドが何をするかは、そのコマンド次第です。そのコマンドはLazySpaceの許可ではなく、自身の許可で動きます。
